# Photo Booth Frame App

文化祭などのイベントで、プリクラ風の写真を撮影・編集・印刷するためのWebアプリです。

フレーム画像と撮影した写真を組み合わせて、オリジナルのフォトシートを作成できます。

## 主な機能

- **フレーム設定**：フレームA・Bを個別に設定・切り替え
- **フレームの読み込み・削除**：透過PNG / WebP形式に対応
- **用紙の向き設定**：L判の縦・横を切り替え
- **写真の配置調整**：写真の位置や拡大率を調整
- **配置プロファイル**：写真の配置設定を保存・読み込み
- **写真エフェクト**：色味や雰囲気を変更するプリセット
- **画像の出力**：完成した写真をPNGとして保存
- **手動での写真取り込み**：カメラから取り込んだ写真を手動で選択可能

※ 機能の詳細や対応状況は、実際の実装に応じて更新してください。

## 動作環境

- Windows
- Google Chrome または Microsoft Edge
- JavaScriptが有効なブラウザ

## 使い方

1. リポジトリをダウンロード、または https://tayut4u.github.io/ を開きます。
2. `index.html` をブラウザで開きます。
3. フレームA・Bに使用する画像を読み込みます。
4. 用紙の向きや写真の配置を設定します。
5. 写真を取り込み、位置やエフェクトを調整します。
6. 完成した画像をPNG形式で保存します。
7. 保存した画像をL判サイズで印刷します。

## フレーム画像について

フレーム画像は、写真を配置する部分が透明になったPNG画像を推奨します。

- 推奨形式：透過PNG
- 対応形式：PNG / WebP
- フレームA・Bはそれぞれ別のデザインを設定できます。

## 写真の配置設定

写真の配置設定はプロファイルとして保存し、同じレイアウトを再利用できます。

ブラウザ内に保存した設定は、使用するブラウザや保存データの状態によっては引き継がれない場合があります。必要に応じてプロファイルを書き出してバックアップしてください。

## 印刷について

L判用紙に印刷する場合は、出力画像の縦横比とプリンターの用紙設定を確認してください。

印刷時に余白や拡大縮小が発生する場合は、プリンター側の設定も調整してください。

## 注意事項

- カメラからの自動取り込みやテザー撮影は、機材・接続方法・ブラウザの対応状況によって利用できない場合があります。
- 学校のネットワーク環境では、一部の機能や外部サービスが制限される可能性があります。
- 文化祭などで利用する場合は、写真の保存先や取り扱いに注意してください。

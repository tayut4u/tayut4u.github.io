# 文化祭 PHOTO STUDIO — Pages再構成版

## GitHub Pagesへ置く
ZIPを展開し、index.html、assetsフォルダ、frames.json、.nojekyllをリポジトリの同じ階層にアップロードします。assetsの中身だけを取り出さず、フォルダ構造を保ってください。
GitHubのSettings → Pagesで公開するブランチとルートを選択します。公開後、そのURLを開いてください。リポジトリ名がURLに付く場合も相対パスで動作します。
HTMLだけでなくassets/studio.jsとassets/studio.cssも必要です。

## 引き継いだ機能
- 1・2・4枚レイアウト、L判縦横、PNG保存・印刷
- 写真の手動選択、ドロップ、待機列、次のお客さま
- 写真のドラッグ・倍率・位置リセット
- 写真窓の数値編集・移動・四隅リサイズ・矢印キー調整
- 編集プレビューの拡大縮小・フレームの薄表示
- 25種の同梱フレーム、手動追加とフォルダ参照
- 追加フレーム一覧と窓位置のブラウザ保存、一覧から削除
- 色フィルター、3D CUBE LUT（2〜65ポイント）、適用強度
- 設定JSONの書き出しと読み込み、旧版JSON対応
- 対応ブラウザでのカメラ保存フォルダ監視

## 旧版からの移行
旧画面で「設定一式を書き出す」を実行し、新しい公開URLで読み込んでください。
同じブラウザ・同じ公開元なら既存の保存設定を利用できます。MacローカルからGitHub Pagesへ移ると保存先が異なるため、JSONで移行してください。
撮影写真は保存されないので読み込み直してください。追加フレームはブラウザ内に保存され、GitHubへ自動アップロードされません。

## 新しいフレーム
assets/frames/1-photo、2-photo、4-photoにPNG/WebPを入れ、update_frames.command（Mac）またはupdate_frames.bat（Windows）でframes.jsonを更新し、画像とJSONをアップロードしてください。Python 3が必要です。
ページの「フォルダの一覧を更新」は公開済みJSONの再取得です。GitHubのフォルダそのものを自動列挙しません。
画面のファイル選択から追加する方法なら、PythonやJSON編集は不要です。追加後に写真窓を調整してください。

## Macローカル
Python 3.9以上でstart_mac.commandを開きます。利用中はターミナルを開いたままにします。URLはhttp://127.0.0.1:8765/です。

## 保存できないとき
写真の枠がすべて埋まると保存できます。エラーはプレビュー下に表示します。
「画像なし」が出る場合はassetsフォルダの配置、ファイル名の大文字小文字、公開完了を確認してください。
設定JSONをバックアップした上でタブを閉じて再度開き、写真を選び直してください。
本番前に実際のMac・ブラウザ・プリンターで保存とL判試し刷りを行ってください。

# 文化祭フォトブース / GitHub Pages用パッケージ

## 公開方法
1. ZIPを展開します。
2. index.html、frames.json、assetsフォルダ、.nojekyllを、GitHubリポジトリの同じ階層にアップロードします。ZIPそのものを置くだけでは動きません。
3. リポジトリの Settings → Pages で Deploy from a branch を選び、アップロードしたブランチと / (root) を指定します。
4. 公開URLを開きます。フレーム一覧から選択すると4枚レイアウトと写真窓が自動設定されます。

通常の静的Webホスティングでも、同じフォルダ構成で使えます。プロジェクト配下のURLにも対応しています。

## 同梱内容
- index.html：アプリ本体
- frames.json：フレーム一覧と写真窓の座標
- assets/frames/：ピンク・ブルー・ミント・グレーのグラデーション4色と、ユーザー提供の元フレーム
- .nojekyll：GitHub Pagesで静的ファイルをそのまま公開するための空ファイル

## フレーム追加
assets/frames/に透過PNGを置き、frames.jsonのframes配列へ項目を追加してください。
既存項目をコピーしてid/name/srcを変更します。layoutはA=1枚、B=2枚、C=4枚。
rectsは各窓の左上x,yと幅w,高さhを画像全体に対する0〜1の比率で指定します。窓の数とlayoutの枚数を合わせてください。
orientationはportrait / landscape / auto。
PNGのファイル名は英数字推奨。JSONはカンマや括弧を含め正しく編集してください。
同梱フレーム選択時は写真窓の位置と写真の拡大率・移動量を登録値に戻します。

## 写真・保存について
撮影写真はブラウザ内で処理し、このアプリからサーバーへ送信しません。
フレームPNGは公開サイトのファイルです。公開したくない写真や情報をリポジトリに入れないでください。
位置・フレームの設定は各端末のブラウザに保存されます。公開先・ブラウザが変わった場合は、設定JSONを書き出して移してください。
公開URLにアクセスするにはネット接続が必要です。オフラインで確実に使う場合は従来のローカルHTMLと手動PNG読み込みをご利用ください。
HTMLをダブルクリックして開いた場合、ブラウザ制限によりframes.jsonの一覧読み込みは使えないことがあります。公開URLではHTTPSで読み込めます。

## 自動取り込み・印刷
対応Chrome / EdgeでJPEG保存先フォルダを選択できます。権限や端末の設定によっては手動読み込みを使ってください。
L判・倍率100%・余白なしで、使用するプリンターに合わせて試し刷りしてください。

## 枚数別フォルダ
- assets/frames/1-photo/：縦写真1枚用（グラデーション4色）
- assets/frames/2-photo/：縦写真2枚を横並び（グラデーション4色）
- assets/frames/4-photo/：縦写真4枚を2×2配置（グラデーション4色＋元フレーム）
全ての窓は3:4です。サイトの1・2・4枚ボタンで表示フレームも切り替わります。
フレームを追加する際は対応するフォルダへ入れ、frames.jsonのsrcとlayoutを合わせてください。

## PCから参照する
「PCからフレームを参照」でPNG / WebPを選択できます。「PCのフォルダをまとめて参照」ではフォルダ内の画像を一覧表示します。1-photo・2-photo・4-photo配下の画像は対応する枚数へ、それ以外は参照時に選んでいた枚数へ登録します。
選択中の画像と設定は各枚数につき1つ、ブラウザへ自動保存されます（保存できない環境では設定JSONを書き出してください）。PCフォルダの参照一覧そのものは再読み込みで消えます。参照した画像はサイトへアップロードされません。

## 公開サイトのフォルダへ画像を追加する
GitHub Pagesではフォルダ内の画像ファイル一覧をアプリが自動取得できないためframes.jsonを使います。
assets/frames/の該当枚数フォルダに画像を追加し、Python 3があるPCでupdate_frames.batを実行してください。既存の登録内容を保ちつつ一覧を更新します。追加画像の写真窓は同じ枚数の既存設定を仮に引き継ぐため、窓が違う場合はframes.jsonまたはアプリで調整してください。
更新後は画像とframes.jsonを一緒にアップロードします。Pythonがない場合はframes.jsonへ手動で登録するか、PC参照で利用できます。

# 文化祭 PHOTO STUDIO — Macローカル対応版

## Macで起動
1. ZIPを展開し、フォルダ一式をMacに置きます。
2. Python 3.9以降を用意します。未導入なら https://www.python.org/downloads/macos/ の公式インストーラでPython 3をインストールします。追加のPythonパッケージは不要です。
3. `start_mac.command` をダブルクリックします。ブラウザで `http://127.0.0.1:8765/` が開きます。
4. ターミナルは使用中開いたままにします。終了するときはControl+C。

commandファイルを直接開けない場合は、ターミナルに `bash `（末尾に半角スペース）と入力し、start_mac.commandをそのウィンドウにドラッグしてEnterを押してください。
Pythonを入れた後はネット接続なしで利用できます。HTMLを直接ダブルクリックするより、この起動方法を使ってください。
別の起動ウィンドウがある場合は二重起動せず、そのURLを開いてください。
Mac実機での起動・印刷は未検証です。本番前に動作とL判印刷を確認してください。

## フレーム追加：方法1（画面から）
1. 1・2・4枚のレイアウトを選びます。
2. 「PCからフレームを参照」または「フレーム・写真窓を設定」のファイル選択でPNG / WebPを読み込みます。
3. 「フレームを選ぶ」内の「追加したフレーム」に登録されます。
4. 「写真窓を調整」で位置を合わせます。追加フレームごとに窓位置と用紙の向きを保存します。
同じ画像・同じ枚数の再登録は重複を避けます。画像の中の透明領域を自動検出する機能ではないので、窓位置は確認してください。
「PCのフォルダをまとめて参照」も一覧に保持されます。1-photo/2-photo/4-photoのフォルダ名から枚数を判別し、それ以外は現在の枚数へ登録します。
一覧から削除してもMac上の元画像は消しません。現在のプレビューも残します。

## 保存先とバックアップ
追加一覧は画像本体を含めブラウザのIndexedDBへ保存します。Macのassetsフォルダへファイルをコピーする動作ではありません。
同じブラウザ・同じURLで使ってください。別ブラウザ、プライベートモード、ブラウザデータ消去、保存容量不足では保持できない場合があります。
「設定のバックアップ」→「設定一式を書き出す」で、追加した全フレーム・窓位置・各レイアウトの設定・LUTをJSONに保存できます。撮影したお客さまの写真は含みません。
以前のGitHub版から移す場合は、旧サイトで設定JSONを書き出し、新版で読み込みます。旧版のJSONに含まれていなかった参照一覧は再登録してください。
設定JSON読み込み上限は80MBです。大量の大きなフレームは方法2を使い、フォルダ一式もバックアップしてください。

## フレーム追加：方法2（フォルダから）
透過PNG / WebPを枚数ごとのフォルダへ入れます。
- assets/frames/1-photo/
- assets/frames/2-photo/
- assets/frames/4-photo/
Macローカル起動時にframes.jsonを更新します。使用中に追加したときは画面の「フォルダの一覧を更新」を押してください。削除したファイルも一覧から外れます。
既存JSONの登録内容は保持します。新しい画像の窓位置は標準値になるため、必要に応じて調整してください。
フォルダ内フレームを選択するとJSONの窓位置へ戻ります。調整位置をフレーム単位で記憶したい画像は方法1で登録してください。
`update_frames.command` はMac用の一覧更新だけのスクリプトです。Windows用update_frames.batも残しています。

## GitHub Pagesでも利用可能
index.html、frames.json、assets、.nojekyllを同じ階層にアップロードします。
GitHub Pagesではフォルダの自動スキャンはできません。Macでupdate_frames.commandを実行してから画像とframes.jsonをアップロードしてください。画面の更新ボタンは公開済みJSONを再取得します。
画面から追加したフレームは各ブラウザにだけ保存され、GitHubへアップロードされません。

## 写真・印刷・カメラ
写真はブラウザ内で処理し、このアプリから外部へ送信しません。
ローカルサーバーは127.0.0.1のみで待ち受けるため、この起動方式ではiPadなど別の端末から接続できません。
カメラの自動取り込みはshowDirectoryPicker対応ブラウザ向けです。ボタンが使えない場合は手動で写真を選択してください。
L判・倍率100%・余白なしを設定し、プリンターのフチなし設定も確認してください。

## 同梱
index.html / frames.json / assets/frames / start_mac.command / serve_local.py / update_frames.py / update_frames.command / update_frames.bat / .nojekyll
既存の25種のフレームと、小画面での重なりを抑えるレイアウトを維持しています。

## 画像が「？」になる場合
同梱フレームが表示されない場合はindex.htmlと同じ場所にframes.jsonとassetsフォルダがあるか確認してください。start_mac.commandで起動し、http://127.0.0.1:8765/を開いてください。
写真も表示されなくなった場合は設定JSONを保存してアプリのタブを閉じ、再度開いて写真を選び直してください。撮影写真は自動保存されません。保存時のエラーはプレビュー下に表示されます。

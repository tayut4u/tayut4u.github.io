文化祭フォトフレーム

フレームA/Bを個別設定 → 写真を配置 → PNG保存 / L判印刷

1. フレーム設定

AとBをそれぞれ先に設定できます。切り替えてもフレーム・向き・写真位置・エフェクト設定は別々に保持されます。

2. 写真を読み込む

3. 写真位置プロファイル（A/B別）

位置・拡大率・エフェクトを自動保存します。同じブラウザで次回開いたときに復元。JSONとして書き出して別PCへ移すこともできます。

4. 自動取り込み（対応ブラウザ）

NX Tetherの保存先フォルダを選ぶと、新しい写真を定期確認します。Windowsの最新版Chrome / Edge推奨。手動読み込みも引き続き使えます。
準備完了。フレームと写真を設定してください。

5. 操作

プレビュー上の写真をドラッグして位置調整。拡大率やプリセットも変更できます。写真とLUTはブラウザ内で処理し、外部サーバーへ送信しません。LUTはAdobe .cube形式に対応。
